## Структура директории

- `draft_marimo.py` - eda, черновики, графики всякие
- `main.py` - основной пайплайн
- `features.py` - feature engineering
- `utils.py`(скорее всего будет не нужен) - мелкие вспомгательные функции 
- `KaggleTemplate.py` - там короче просто можно вести заметки, трекать вручную модели и их лоссы и эксперименты разные и записывать идеи
